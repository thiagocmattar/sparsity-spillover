# Analysis 020: intervention-centered manuscript revision

Authorized by the user's request to execute the updated `manuscript/draft/task.md`.
Mode: EXISTING_EVIDENCE. This analysis reads retained records, derives CPU summaries
and mathematical checks, and generates paper figures. No training, checkpoint
reevaluation, GPU measurement or paid job is authorized or performed.

The source cohort remains 54 primary conditions. The prior h-only pressure cohort
is separate. New work covers OL1 geometry/saturation, analytic reach, ReLU followed
by post-hoc clipping, selected cross-size comparisons and retained training logs.
Figure and result observations belong in `observations/`; machine-readable
reductions belong in `data/`. Raw records remain in their original run folders.

The [task handoff](../../manuscript/draft/revision-v2/readiness.md) contains the
claim ledger, task-to-paragraph map, verified/conditional/unresolved report and
full regeneration/build/test commands. Existing Analysis 018/019 scientific
records are inputs, not newly measured outcomes.

## Outputs and findings

- `01_audit_logs.py`: verifies 336 manifest source references and log semantics;
  writes `data/log-audit.json`, 24,208 OL1 boundary rows, 6,408 training-curve
  records and `tables/training-dynamics.tex`. The cap activates on 7,283 OL1
  boundaries (30.09%), with sharply different rates across recipes and sizes.
  One corrupt A1-H first-boundary line lies outside these selected reductions.
- `02_cross_size.py`: verifies 36 final-checkpoint manifest identities, joins
  396 FP16 trained/clipped records and writes the full ReLU/clipping comparison.
  High-threshold A7-OL1 improves both axes over A4-OL1 at all three sizes;
  low-threshold orderings differ. ReLU's clipping benefit is regional.
- `03_figures.py`: creates four vector PDFs: expanded main/full-range cross-size
  plots, raw training dynamics, and runtime quality/latency plus sparse-factor
  panels. `figures/SOURCES.json` records input hashes and every omitted main-panel
  point. The cross-size displays contain 96 distinct evaluations in two views.
- `04_verify_claims.py`: checks 40 displayed roundings and condition identities,
  ordering, saturation, trajectory signs, runtime ratios and figure omissions;
  writes `data/claim-checks.json`.
- `geometry.py`, `test_geometry.py`: ideal OL1 and analytic reach checks, including
  stabilizer limits, task-gradient counterexample, boundary derivatives, integer
  operation inventory, overlap/closure and width/depth/sequence effects.
- [observations/INDEX.md](observations/INDEX.md): question, method, coverage,
  result, caption and caveats for each scientific output.


Scripts 01–02 need original local logs/configs/manifests and frozen source
inventories at the paths in Analysis 018, plus Run 030's retained clipping release.
Some inputs are ignored local evidence. They cannot be reconstructed from a
fresh Git checkout alone. Scripts 03–04 use the checked-in derived records,
Analysis 018/019 inputs and existing plot helpers; they need no weights or GPU.
The project environment provides CPU PyTorch, NumPy, Matplotlib, PyYAML and pytest.
The dynamics table is generated by script 01 and also retained as TeX.

The scripts all passed. Together with the existing pressure, site, reach and
evidence tests, **67 focused tests passed**. All four new PDFs and the generated
table are copied byte-for-byte into the draft. The original twelve table fragments
and eight Analysis 019 numerical PDFs reproduced unchanged. Live source metadata
was refreshed after the manuscript build; original scientific values did not change.

The paper distinguishes FP16 loss/counts from BF16 timing/reference quality,
ideal adaptive-direction geometry from actual-loss behavior, and observed late
improvement from a causal stopping explanation. No new measurement is required
for the current wording. Optional seeds, extra clipping targets or continuations
are separate requests in the handoff and were not launched.
