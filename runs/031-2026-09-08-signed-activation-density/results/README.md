# Signed activation-density measurements

Seven complete Pythia-14M checkpoint evaluations for Analysis 018 Figure 05-v3.
All 500 validation documents are represented in the 338 complete 2,048-token
blocks; the 1,444-token tail is excluded. No weights or gates were changed.

`histograms/*.json.gz` contains the lossless structured measurements. Each file
includes the source checkpoint/config/cache identity, validation loss/coverage,
30 layer/site histograms, five pooled sites, two pooled groups, moments,
exact-zero/near-zero counts, extrema, tails, hook metadata, dtypes and timing.
Counts are integers; these files contain no model weights or validation tokens.

The signed native grid has 16,000 bins over [-8,8] with nominal width .001.
Reconstruct its exact edges with `numpy.linspace(-8,8,16001,dtype=numpy.float32)`.
Bins are left-closed/right-open, except the final bin includes +8. Exact zeros
are excluded from every histogram and stored in `exact_zero_count`.
`underflow` and `overflow` retain the out-of-grid tails. For each row/group,
histogram + underflow + overflow + exact zeros partitions its total exactly.

FFN combines h,m with 80%/20% element weights; attention combines post-RoPE
q,k and v equally. To obtain density, divide bin counts by **all captured
elements times actual bin width**. Do not renormalize to nonzero mass. The
publication figure sums ten native bins into each display bin.

- `manifest.json`: completed keys, code hashes, precision and environment.
- `verification.json`: coverage, zero/tail totals, memory and timing by checkpoint.
- `scientific-verification.json`: agreement with retained losses/site statistics
  and 108 checks of empty trained-gate regions, allowing one native boundary bin
  for FP16 rounding. Maximum absolute loss discrepancy: 0.0000688543.
- `calibration.json`, `cuda-boundary-checks.json`: three-checkpoint CUDA smoke,
  FP16/FP32 signed-boundary controls and 1.78 GB peak reserved memory.
- `environment.txt`, `gpu.txt`, `setup.log`, `events.jsonl`: execution records.
- `inventory.json`: byte sizes and SHA-256 values for this release.
