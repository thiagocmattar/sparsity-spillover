# Manuscript status reports

This ignored workspace contains dated, point-in-time status reports for the
manuscript and its supporting experiments. Reports use the sequential naming
scheme `NN-YYYY-MM-DD-name/`; `NN` is a two-digit sequence local to this
directory.

Each report folder should keep its editable TeX source and compiled PDF
together. A report is a project-status artifact, not a consolidated research
finding or manuscript claim. Evidence status and provenance must therefore be
stated inside each report.

## Reports

- `01-2026-08-30-status-update/`: Pythia-14M ladder status through Run 015,
  with historical Run 012 retained in an appendix.
- `02-2026-09-01-status-update/`: selected Pythia-14M/70M ladder status through
  Run 018 and Analysis 010, including the current RunPod billing refresh.
