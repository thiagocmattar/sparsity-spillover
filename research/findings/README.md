# Findings

Create one user-approved conclusion per file:
`FNNN-short-statement.md`.

Each finding records status (`confirmed`, `tentative`, or `discarded`), date,
source run/analysis and scripts, exact statement with n and coverage, evidence,
definitions, caveats, and what would change the conclusion. Candidate findings
stay in run observations until the user approves consolidation.

When a finding changes the manuscript, record the affected `.tex` section and
the exact statement/table it supports. Manuscript prose does not upgrade a
candidate observation into a finding by itself.
