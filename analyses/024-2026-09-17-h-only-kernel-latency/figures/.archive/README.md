# Previous Analysis024 figures

All 13 PDFs that were directly in `figures/` before the task.md rebuild were moved
here on 18 September 2026 at the user's request. Bytes and SHA-256 hashes were
recorded before the move and verified afterward; see [inventory.json](inventory.json).
The previous repository state was commit `2905f8b`.

These files are historical outputs of scripts 02 through 12 in Analysis024.
Their original provenance records can still name `figures/<old-name>.pdf`:
the inventory maps those unchanged names/hashes to this archive. Existing historical
JSON hash records have not been rewritten. Historical Markdown links in this analysis
now point to the archived PDFs. The old scripts are retained as history; some read
old figure paths and should be reproduced in their historical checkout rather than
used to rebuild the current paper set.

The current nine publication PDFs are generated by `13_rebuild_paper_figures.py`
and indexed in [CAPTIONS.md](../../CAPTIONS.md).
